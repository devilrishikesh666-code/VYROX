# VYROX STUDIO

A creative photo and video editing website.

## Developer

Rishikesh Singh

## Features

- Premium responsive interface
- Photo editor
- Brightness adjustment
- Contrast adjustment
- Saturation adjustment
- Warmth adjustment
- Image rotation
- Image flipping
- Photo filters
- PNG export
- Video preview
- Audio upload and playback
- AI creative assistant
- Responsive mobile design

## Installation

Install Node.js 18 or newer.

Run:

npm install

Configure your environment variables.

Start:

npm start

Open:

http://localhost:3000

## AI Configuration

Set these environment variables:

AI_API_KEY=your_private_api_key

AI_API_BASE_URL=https://openrouter.ai/api/v1

AI_MODEL=openai/gpt-4o-mini

Never publish your API key.

## Important

This starter project includes basic browser-based photo editing and
video preview. It is not a complete professional video-rendering
engine. Advanced video rendering and AI image editing require
additional integrations.
